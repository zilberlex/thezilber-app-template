# Composable Renderable Boundary Spike

Place this folder at:

`src/routes/composable-renderable-boundary-spike/`

Run:

```bash
pnpm exec svelte-check --tsconfig ./src/routes/composable-renderable-boundary-spike/tsconfig.json
```

Then start the app and open:

`/composable-renderable-boundary-spike`

The spike verifies that precise factory results can cross into a lightweight renderer prop boundary without expanding the full HTML prop union.
